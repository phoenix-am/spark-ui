## Features

- The building blocks under the components: `ButtonBase`, `InputBase`, `Popover`, `ListBox` (with `ListItemContent`) and `Overlay`.
- They carry Sparkwire's behaviour and look, so components you build match the rest.

## Accessibility

- `ButtonBase` handles keyboard activation and disabled state for any element; `Popover` and `Overlay` handle focus, dismissal and portals; `ListBox` handles selection and announcements.

## Best practices

- Use them to build components Sparkwire doesn't ship; reach for the finished components first.

## Limitations

- The base layer is experimental: unlike the components, it may still change in minor versions.
