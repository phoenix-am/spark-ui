## Features

- A tiny trend line with no axes, sized with `width` and `height`.
- `area` fills under the line; `showLast` marks and labels the latest value.

## Accessibility

- Give it an `aria-label` that says what the trend means (“Revenue this month, rising”); it's announced as an image.

## Best practices

- Put the actual number next to it; a sparkline shows the shape, not the value.
- Use the same width for sparklines in a table so rows compare at a glance.
