## Features

- Whole screens built from Sparkwire: a dashboard, a sign-in page and a settings page.
- Copied into your project with `npx sparkwire add`, so you own the code and can change anything.

## Responsive behavior

The dashboard's stat cards and charts rearrange below 900px and 480px, its menu turns into a drawer on phones, and the settings page stacks below 640px.

## Best practices

- Treat a block as a starting point: replace the sample data and remove what you don't need.

## Limitations

- Blocks aren't part of the npm package; they're added as source with the CLI.
