# Spark UI · Live Wire

**Components that carry current.** Spark UI is a React component library whose
default theme, Live Wire, takes the name literally:

- **Buttons** throw sparks from the press point.
- **Switches** are levers that close a circuit and light a bulb.
- **Textfields** charge up as their value becomes valid.
- **Tabs, Accordions and Progress bars** show current flowing through the active part.
- **Modals** arrive like a power cut: the page flickers and dims.

Every animation respects the operating system's *reduce motion* setting.

## Install

```bash
npm install @spark-ui/core
```

## Use

```tsx
import '@spark-ui/core/styles.css'; // once, e.g. in app/layout.tsx

import { Button, Switch, Textfield } from '@spark-ui/core';

export function App() {
  return (
    <>
      <Textfield label="Password" type="password" charge={(v) => v.length / 8} />
      <Switch label="Power" defaultChecked />
      <Button>Ignite</Button>
    </>
  );
}
```

No provider or CSS-in-JS runtime is needed, so components work in React Server Component pages.

## Theme

Use the **Mode** button in the toolbar above to switch between dark and light. In an app, set `data-spark-theme="light"` (or `"system"`) on `<html>`, and override any token as a CSS variable, for example `--spark-energy-current`. See **Foundations / Tokens** for every value.

## Packages

| Package | What it holds |
| --- | --- |
| `@spark-ui/core` | The components |
| `@spark-ui/styles` | Theme tokens: colours, energy, surfaces, motion |
| `@spark-ui/system` | `ThemeProvider` and `useTheme` |
| `@spark-ui/icons` | About 860 SVG icons as React components |
| `@spark-ui/utils` | Helpers such as `alpha()` and slot utilities |
