# Sparkwire starter

A small Vite + React app built with [Sparkwire](https://github.com/phoenix-am/spark-ui): a form, a chart and a data table, with the energy dial and light mode in the header.

[![Open in StackBlitz](https://developer.stackblitz.com/img/open_in_stackblitz.svg)](https://stackblitz.com/github/phoenix-am/spark-ui/tree/master/examples/starter?file=src/App.tsx)

Run it locally:

```bash
npx degit phoenix-am/spark-ui/examples/starter my-app
cd my-app
npm install
npm run dev
```
